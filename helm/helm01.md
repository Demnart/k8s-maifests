# Основы Helm

## Что такое Helm? 

Helm - менеджер пакетов Kubernetes.

Как любой менеджер пакетов, Helm упрощает задачу управления жизненым циклом приложения. 

Update & delete приложений достаточно простые(ну почти всегда). В этом цикле займемся разбором/созданием собственных пакетов (chart): их установкой и кастомизацией.

## Как работает Helm

Пакет(helm chart или просто chart), обычно распрострастраняется в виде стандартного архива в формате .tar.gz . Внутри которого находится: 

  - Описание чарта.  
  - Шаблоны манифестов.  
  - Конфигурационные параметры приложения по умолчанию.  
  - Другие, не обязательные файлы.  

Для хранения набора таких пакетов можно использовать любой WEB-server с обязательным файлом index.yaml, в котором описываются чарты? которые предоставляются данными сервером. Но это самый простой способ создания репозитория. В приципе хранить архивы паетов можно в спец-ых системах или универсальных приложениях, которые поддерживают helm charts типа - Nexus, Harbor и т.д.  

Так же чарт можно хранить например в локальной файловой системе, не запаковывая его в архив, в виде структуры и директорий. Но в этом случае затруднена версионость чарта. Т.е. для разных версий чарта необходимо создавать отдельные директории. Ситуацию может облегчить хранения файлов чарта в системе контроля версии, напрмер в git.

Основная задача helm:

  - Получить от пользователя информацию, какие конфигурационные параметры приложения необходимо переопределить. Обычно для этого используется кастомный файл values.  
  - Учитываюя параметры, сгенерировать из шаблона файлы манифестов приложений.  
  - Итоговые файлы манифестов поместить в kubernetes API.  
  
Helm не может управлять приложениями, установленными не с помощью Helm.

Установка:

Установить helm можно различными способами: 

  - Скачать архив с бинарным файлом.  
  - Установить с помощью скрипта, который сам загрузить нужный бинарник и разместить его /usr/bin .  
  - Воспользоваться пакентным менедежером.

Всю информацию по установке можно найти в [документации](https://helm.sh/docs/intro/install).
